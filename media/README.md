# متّة على المزاج

الفيلم النهائي في جذر المشروع: `mate_on_your_terms.mp4` — ‏1080p ‏(1920×1080)، ‏24 إطار/ثانية، ومدته نحو 34 ثانية.

يتضمن مشهد سهرة شامية واقعيّ المظهر مع نساء ورجال من أعمار مختلفة، متّة وتسالي، وثلاثة أباريق على الغاز بدرجات مختلفة. أُضيف فوق كل إبريق مؤشر بصري لحرارة الماء: **100°م، 80°م، 60°م** مع مقياس حرارة ملوّن. هذه قيم توضيحية ضمن التصميم وليست قراءات من حساس حقيقي.

تظهر ثلاث كاسات متّة بتعابير مختلفة (مبتسمة، محتارة، ومنزعجة)، وتتحدث الكاسات بالسؤال المطلوب وحده: **«انتو كيف بتحبوني؟»**. لا توجد قبله عبارة تمهيدية من نوع «طيب يا كاسة».

## الملفات

- `../mate_on_your_terms.mp4` — الفيديو النهائي (في جذر المشروع).
- `create_mate_video.py` — سكربت تركيب المشاهد والحركة والمؤشرات والترجمة والصوت.
- `mate_wide.png`, `mate_kettles.png`, `mate_expressions.png` — الصور السينمائية المستخدمة.
- `voice_female_intro.mp3`, `voice_male_reply.mp3`, `voice_cup.mp3` — المقاطع الصوتية المستخدمة.
- `requirements-video.txt` — متطلبات إعادة بناء الفيديو.

لإعادة التصدير بعد تثبيت المتطلبات، شغّل من جذر المستودع:

```bash
python -m pip install -r media/requirements-video.txt
python media/create_mate_video.py
```
