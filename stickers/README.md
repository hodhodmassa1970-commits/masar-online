# ستيكرات شخصيه هيا — Haya Stickers

حزمة ستيكرات لشخصية «هيا» مكتوب عليها: **معكم هيا** و **كونوا مع هيا** (مع تنويعات قصيرة أخرى).

## المحتويات

| المجلد | الوصف |
|---|---|
| `png/` | 9 ستيكرات PNG بخلفية شفافة — 512×512 مع إطار أبيض (die-cut) |
| `webp/` | نفس الستيكرات بصيغة WebP (أخف للواتساب) |
| `preview/sheet.png` | لوحة معاينة لكل الستيكرات |
| `haya-stickers.zip` | الحزمة كاملة (PNG + WebP) للتحميل بضغطة واحدة |
| `index.html` | صفحة معرض الستيكرات مع أزرار التحميل |
| `cut/` | شخصيه هيا مقصوصة بخلفية شفافة قبل إضافة النص |
| `tools/` | سكربتات بايثون لتوليد الحزمة من جديد |
| `fonts/` | خط Cairo ExtraBold (SIL OFL) المستخدم في النصوص |

## إعادة التوليد

```bash
python -m venv .venv && . .venv/bin/activate
pip install pillow numpy scipy uharfbuzz freetype-py

python tools/make_stickers.py      # ينتج png/ و webp/ و preview/sheet.png
```

`tools/make_cutouts.py` يوثّق خطوة القصّ من صور الخلفية الخضراء (chroma key)؛ يحتاج مجلد `raw/`
بالصور الأصلية وهو غير مضمَّن في المستودع للحفاظ على حجمه صغيرًا — ملفات `cut/` الناتجة مضمَّنة.

## تعديل النصوص

كل الستيكرات ونصوصها في قاموس `STICKERS` أعلى ملف `tools/make_stickers.py`:

```python
("01-wave", "معكم هيا", "pink", "bubble"),
```

- العمود الثاني: النص العربي (يُشكَّل تلقائيًا عبر HarfBuzz، فلا حاجة لكتابة الحروف منفصلة).
- العمود الثالث: الثيم اللوني (`pink`, `rose`, `lavender`, `mint`, `cream`, `blue`).
- العمود الرابع: النمط (`bubble` شريط أعلى الستيكر، `card` لوحة بين اليدين).

## الاستخدام

- **واتساب**: ثبّت تطبيق Sticker Maker ثم استورد ملفات `png/` (3–30 ستيكر لكل حزمة).
- **تيليجرام**: `/newpack` ثم أرسل الصور.
- **التصاميم**: الملفات شفافة وغير مضغوطة، مناسبة للستوري والبوستات.
